Submit an Event

For venues, promoters, and organizers to add their own listing to the Detroit Arts & Events Calendar — the same self-service model Cleveland's calendar uses (organizations register, log in, and submit their own events).

In a live version: you'd sign in as a registered venue/organizer before reaching this form, so submissions are tied to a real account and can be moderated.
What this is: a working front-end for event submission — validation, category picker, and a confirmation step all function. It does not save anywhere yet. A real version needs a backend: a database, a moderation/review queue before events go live (to prevent spam), email verification for new organizers, and duplicate-detection against the other sources already feeding the calendar.
