Moderation queue for venue/organizer submissions and event feeds
Admin access
Enter the admin secret configured in Vercel (ADMIN_SECRET).

Event submissions

Single events submitted via submit.html — approve to publish, reject to discard.

Feed sources

Ongoing calendar feeds organizers registered via submit.html's "Submit your event feed" form. Approving one does not publish anything by itself — it lets api/cron-feeds.js start pulling from that URL on its normal daily schedule. Each feed's own events then land pre-approved, since the feed itself was the thing reviewed.

Live events

Search anything currently live on the site — from any source, including automated feeds — and remove it if it doesn't fit the brand. Removing is reversible from "Recently hidden" below.

Recently hidden

The last 20 events removed via Reject or Remove from site. Restore brings one back to the live site.
