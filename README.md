# 313 Events — Detroit Arts & Events Calendar

A comprehensive, filterable calendar of arts, culture, and nightlife events
in the City of Detroit, modeled on ClevelandArtsEvents.com.

- `index.html` — the calendar (month view, list view, category filters, search)
- `submit.html` — venue/organizer event submission form (front-end only, no backend yet)

## Status

Prototype. Events are hand-curated from venue sites and event platforms
(19hz.info, Paxahau, Resident Advisor, Dice, Eventbrite venue pages, and
direct venue sites like dia.org, mocadetroit.org, easternmarket.org).
Not a live feed yet — see the notice banner in index.html for full source
list and known gaps.

## Deploying

Static site, no build step. Deploys as-is to Vercel, Netlify, GitHub Pages,
or Cloudflare Pages.
