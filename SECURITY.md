# Security policy

## Reporting a vulnerability

Please report suspected security problems privately. Do not open a public GitHub issue, pull request or comment that describes the problem, and do not post details in any public place.

Send your report to: **[SECURITY-CONTACT-PLACEHOLDER: the 313.events owner fills in a reporting address before this file is released]**

Helpful details to include:

- what you found and where (page, API route, or file);
- the steps to reproduce it, as short as you can make them;
- what you think the impact is;
- how to reach you for follow-up questions.

## Please do not

- access, change or delete data that is not yours;
- run automated scans or load tests against the production site;
- share the details with others before the owner has had a chance to respond.

## Scope

This repository and the public site 313.events. Reports about third-party services (for example, the hosting or database providers) should go to those providers directly.

## Notes

The owner maintains the detailed security and operations findings privately. This public file only says how to reach the owner.
